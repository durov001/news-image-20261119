One front page for Thursday 19 November 2026: 35 world-news stories
from the day, laid out as a single newspaper image. Built for the
make.fun news-image-20261119 bounty.

## What it does

`main.ts` copies the front-page image (`entry.png`) into the output
directory exactly as committed — no re-rendering, no changes, so the
judged image is byte-for-byte the one in this repository.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
